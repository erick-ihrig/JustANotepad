# Changelog

## Unreleased

- First working version: a floating text box with named page tabs that saves as you type.
- The box, tabs and controls fade away when the notepad isn't hovered or focused; the eye control lets the text fade too.
- Escape only stops typing. Nothing but the close control, `/note`, the keybind or a launcher closes the notepad.
- Page tabs in a thin row above the text box, with small controls (search, undo, insert location, eye, close) at the right end of the same row. Each control can be hidden in the settings.
- Optional separate pages per character, minimap button, Escape-menu button and addon compartment entry.
- Reopens at login if it was open at logout.
