# Changelog

## Unreleased

- First working version: a floating text box with named page tabs that saves as you type.
- The box, tabs and controls fade away when the notepad isn't hovered or focused; the eye control lets the text fade too.
- Escape only stops typing. Nothing but the close control, `/note`, the keybind or a launcher closes the notepad.
- Page tabs in a thin row above the text box, with small controls (undo, add a to-do, eye, close) at the right end of the same row.
- The search icon sits under the bottom-left corner of the window; its box pops out to the right of it.
- Each control can be hidden in the settings.
- A faint border stays around the box when the notepad fades; a slider sets how visible it is, down to none.
- Two kinds of page side by side: for all characters, or for one character only (tinted tabs).
- To-do lines anywhere in a page: a checkbox that strikes the line through, and a delete circle on hover. Long to-dos wrap under their own indent.
- Left-click + adds a page for all characters, right-click + adds one for this character; a tab's menu converts between the two.
- Highlighted text can be converted into to-dos from a right-click menu, one to-do per line.
- The window can be dragged by any empty space in it.
- Holding a movement key while typing stops typing and takes back the held letters. (Release and press the key again to move.)
- A welcome page on a new install that explains how to use and set up the notepad.
- Optional minimap button, Escape-menu button and addon compartment entry.
- Reopens at login if it was open at logout.
