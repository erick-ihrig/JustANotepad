# One lock, not two

*16 November 2026, added in 1.2.0*

## The problem

Even faded out, the notepad is still there, and it still takes clicks. Clicking on the game world behind it could land in the notepad instead, and suddenly I was typing into a note.

## The idea

I wanted a button that makes the whole notepad click-through, so clicks go straight to the game. The addon already had a "Lock Window" setting that stopped moving and resizing. I couldn't think of a case where you'd want one without the other: if the window is pinned in place, you also don't want it grabbing clicks. So they became one feature. Locked means fixed in place and click-through.

## How it behaves

- A lock button sits alone at the top-left, just left of the tabs, away from the other buttons. It's the one thing that still takes clicks, so you can always unlock.
- While locked, hovering the notepad shows only the lock button. The tabs, border and other buttons stay faded, because none of them would do anything anyway.
- The to-do checkboxes still work while locked, so you can tick things off without unlocking. The delete circles don't appear, since they can't be clicked.
- `/note lock` and the Lock Window setting do the same thing as the button.

## How it works

Every part of the notepad that takes the mouse is switched off when you lock it: the window, the text boxes, the tabs, the buttons, the scrolling. The addon remembers exactly which ones it switched off and switches back on only those when you unlock, so nothing that was meant to ignore the mouse suddenly starts catching it.

Some details that came up while building it:

- **New things appear while locked.** Switching pages creates new rows and tabs, which take the mouse by default. The lock runs again after every redraw to catch them.
- **Hovering still works.** Fading in on hover doesn't need the mouse to be "on" for the frame; it only checks where the pointer is. That's why the lock button can still appear on hover.
- **Links are separate.** Links in text take clicks on their own, separately from the text box, so the first version still let you click links while locked. The lock now turns links off too.
- **No invisible click targets.** If your text is set to fade out completely, the checkboxes would be invisible but still clickable while locked. In that case they're switched off as well.

## Trade-offs

You can't scroll or switch pages while locked. That's the cost of "everything except the lock". So far it's the right trade, since locking is for when you're playing, not reading.
